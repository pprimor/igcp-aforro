# igcp-aforro docs

[Astro Starlight](https://starlight.astro.build) site for `igcp-aforro`. Deployed to Cloudflare Pages by the release workflow.

## Local development

```bash
cd docs
pnpm install --ignore-workspace
pnpm dev
```

The dev server runs on [http://localhost:4321](http://localhost:4321). The API reference under `/api/*` is generated by [`starlight-typedoc`](https://starlight-typedoc.vercel.app/) on every build, sourced from `../src/index.ts` and the project's `tsconfig.json`. Generated files land in `src/content/docs/api/` and are git-ignored.

The generated API reference is English-only for now because it is built from the package TSDoc comments. Both Portuguese and English authored pages should link to `/api/` as the canonical API entry point.

## Deploy

The production site is served from the domain root. Build locally with:

```bash
pnpm build
```

The compiled site lands in `docs/dist/`.
