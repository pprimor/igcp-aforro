Choose Série D, E, or F, set a subscription date, the number of units, and an "as of" date to see the live `SimulateResult` summary, the per-quarter schedule, and the mid-quarter accrued interest. The numbers are produced by the same `simulate()` function the npm package and CLI use. Copy a share link to reopen the current scenario with the same values, and see the [Methodology](/en/methodology/) page for how each figure is derived.
