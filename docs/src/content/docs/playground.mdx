import Playground from '../../components/playground/Playground.tsx';

Set a subscription date, the number of units, and an "as of" date to see the live `SimulateResult` summary, the per-quarter schedule, and the mid-quarter accrued interest. The numbers are produced by the same `simulate()` function the npm package and CLI use — see the [Methodology](/methodology/) page for how each figure is derived.

:::note[Série E in the playground]
The interactive playground is currently locked to **Série F**. Adding a series switcher (with per-series subscription-window and unit-range validation) is tracked as a follow-up; in the meantime, Série E cohorts can be simulated via the npm package or `aforro --series E`. See the [Quickstart](/quickstart/) for an example.
:::
