import Playground from '../../components/playground/Playground.tsx';

Escolha a Série E ou a Série F, indique a data de subscrição, o número de unidades e a data de referência para ver o resumo `SimulateResult`, o calendário trimestral e o juro acumulado a meio do trimestre. Os números são produzidos pela mesma função `simulate()` usada pelo pacote npm e pela CLI. Consulte a página de [Metodologia](/methodology/) para perceber como cada valor é calculado.
