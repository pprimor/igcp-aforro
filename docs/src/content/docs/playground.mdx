import Playground from '../../components/playground/Playground.tsx';

Escolha a Série C, D, E ou F, indique a data de subscrição, o número de unidades e a data de referência para ver o resumo `SimulateResult`, o calendário trimestral e o juro acumulado entre capitalizações. Os números são produzidos pela mesma função `simulate()` usada pelo pacote npm e pela CLI. Pode copiar uma ligação para partilhar o cenário atual com os mesmos valores. Consulte a página de [Metodologia](/methodology/) para perceber como cada valor é calculado.
